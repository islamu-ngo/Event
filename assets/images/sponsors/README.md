# Supporter logos

These assets are stored locally so the root README and public documentation do not depend on third-party image servers. On 2026-11-13, the project maintainer confirmed that GitBook and Gitar requested acknowledgment in the README or website and granted permission to display their logos for those acknowledgments.

- `gitbook.svg`: GitBook icon from [Simple Icons 14.15.0](https://cdn.jsdelivr.net/npm/simple-icons@14.15.0/icons/gitbook.svg), distributed under [CC0 1.0](https://cdn.jsdelivr.net/npm/simple-icons@14.15.0/LICENSE.md). Colored blue to match the previous README icon.
- `gitar.svg`: Gitar wordmark downloaded from the [existing Sonar asset URL](https://assets-eu-01.kc-usercontent.com/ef593040-b591-0198-9506-ed88b30bc023/22779193-4b6d-4bdf-a860-37007a6d2315/gitar-wordmark.svg), displayed under the permission confirmed by the maintainer. The artwork is unchanged; explicit display dimensions preserve its proportions.

Identical copies live in `docs/public/documentation/.gitbook/assets/sponsors/` so they remain inside the GitBook documentation space during synchronization. Update both copies together.
