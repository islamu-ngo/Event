# Noto Sans Arabic

`NotoSansArabic[wdth,wght].ttf` is the unmodified variable font from
[Google Fonts](https://github.com/google/fonts) commit
[`9fab8b6cc7b2f20376914fd765d918c698c66d75`](https://github.com/google/fonts/tree/9fab8b6cc7b2f20376914fd765d918c698c66d75/ofl/notosansarabic).
The upstream font blob is `f1d01edce4ebaedcbe9a06fc75fec07b304ec3df`.

`OFL.txt` is the unmodified upstream SIL Open Font License. The API project
embeds the font as an assembly resource so rendering never requires a host font
lookup or Fontconfig.
