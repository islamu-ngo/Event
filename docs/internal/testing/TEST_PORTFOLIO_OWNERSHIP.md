## Reading A Cohort And Its Method Variants

A logical cohort is a compiled type and its protected assertion families. It can span many physical `.cs` files. Select its compiled class when running TUnit; file stems and partial-file suffixes are not selectors. `HumanSettingsMutationPreparationTests`, `NativeEventPublicActionsHttpTests`, `HumanAccountMembershipCustodyTests`, `WebhookLocalDeliveryNativeAuthorityTests` and `CombinedEventResourceTransportTests` are concrete examples.

The native index has the following structure:

| Element | Meaning and limit |
| --- | --- |
| `Projects[].Path`, `DefineConstants` | Evaluated project identity and compiler symbols for the selected configuration; this is not a runtime host profile. |
| `Sources[].Path`, `Sha256`, `Owners[]` | Physical source hash and every evaluated compiling project, including the actual `Link` metadata. A shared helper is indexed once with multiple owners. |
| `Declarations[].Type`, `Line`, `Partial`, `CompiledOwners` | Namespace/type identity and declaration location under each owner's effective compiler symbols. Partial declarations must be joined by type **within an owner**; equal namespaces in separate assemblies are not one fixture. |
| `Declarations[].Attributes`, `BaseTypes` | Declared class data sources, categories and fixture inheritance. An absent attribute is not evidence that the constructor or helper has no runtime dependency. |
| `Tests[].Name`, `Parameters`, `Attributes`, `Line` | Exact declared method identity/signature and literal `Arguments`, `Values`, parameter attributes or dynamic data-source expressions. Dynamic provider expressions are preserved, never evaluated or expanded into invented cases. |
| `Projects[].Assets[]` | Evaluated `Content`, `None`, `EmbeddedResource` and `AdditionalFiles`, their kind/link, existence and hash. A default `None` item is not proof that a test consumes it. External SDK/package assets are references only: `External=true`, `Exists=null`, `Sha256=null`; the tool does not open them. |

This is an evaluated-input index. Target-generated compiler files, inherited test expansion, runtime `MethodDataSource`/`ClassDataSource` contents and runner-generated variants still require the actual runner's discovery/result identities. A method with two literal arguments is not automatically two admitted executions. Provider/profile identity and the named case outcomes must be reconciled against a retained result from the final candidate.

`retain` preserves an active assertion family in its current owner. `replace` preserves the family while changing its assurance seam. `move` changes its execution owner and preserves all assertions/variants. `delete-obsolete` requires demonstrated removal of the protected production contract. `delete-duplicate` requires an identified stronger surviving assertion family and passing evidence. None of these decisions permits removing a guard before required replacement execution passes. No additional current cohort is classified `delete-duplicate` in this record.

## Reproduce Structural Ownership Without Building Hosts

Run from the task worktree with the approved scratch directory. The metadata command evaluates the actual SDK/project item includes and excludes without executing build targets, running a host or reading injected secrets. The following commands emit **structural** source/asset evidence only:

```bash
export TMPDIR="$HOME/.cache/agent-tmp"
portfolio_output="$TMPDIR/testing-assurance-modernization/continuation/portfolio"
mkdir -p "$portfolio_output"
set -- "$PWD" --portfolio
for project in tests/*/*.csproj eng/*/tests/*/*.csproj; do
  project_name="${project##*/}"
  metadata="$portfolio_output/current-ownership.${project_name%.csproj}.json"
  dotnet msbuild "$project" -nologo -p:Configuration=Release \
    -getProperty:MSBuildProjectFullPath,DefineConstants \
    -getItem:Compile,Content,None,EmbeddedResource,AdditionalFiles > "$metadata" || exit
  set -- "$@" "$metadata"
done
dotnet run --project eng/tools/Explore.AssuranceAudit/Explore.AssuranceAudit.csproj \
  --configuration Release --no-build -- "$@" > "$portfolio_output/current-ownership.index.json"
git rev-parse HEAD > "$portfolio_output/current-ownership.head.txt"
git status --porcelain=v1 > "$portfolio_output/current-ownership.worktree.txt"
sha256sum "$portfolio_output"/current-ownership.*.json
```
